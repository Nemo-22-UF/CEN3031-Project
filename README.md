# CEN3031-Project
Duolingo-style app that teaches cooking skills. CEN3031 Fall 2026 team project

## Recipe data
Recipes come from [TheMealDB](https://www.themealdb.com/), used under its free
API terms for educational use. Recipe data is imported into each developer's local
database and is not stored in this repository. See
[docs/recipe-source.md](docs/recipe-source.md) for the source decision, field
mapping, and usage rules.
